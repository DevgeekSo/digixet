# Reels — Social & UGC Agency Website Clone

A high-performance clone of the [Reels Webflow Website](https://reels-wbs.webflow.io/).

## 🚀 Overview

This repository contains the complete clone of the Reels agency website, including all pages, responsive layouts, GSAP animations, Lenis smooth scrolling, Webflow interactions, creator showcases, video backgrounds, pricing tables, case studies, and blog articles.

## 🛠️ How to Run

To run the local server with clean URL support (so `/about` serves `about.html`, etc.):

```bash
npm start
# or
node server.js
```

Then open your browser at **[http://localhost:3000](http://localhost:3000)**.
